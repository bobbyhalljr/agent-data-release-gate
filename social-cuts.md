Nothing was written to the remote account. Your data still left the building.

Composio launched Instant on October 8, making supported paid tools available without separate provider signups. That's useful. It also makes data release an application decision you need before dispatch.

I built a tiny TypeScript gate. The model selects record IDs and fields. Trusted application state supplies the values, tenant ownership, classifications, and recipient policy.

25 local checks pass. Public company fields pass the research route. Internal notes do not. Another tenant's record is rejected even when its fields are public.

Fictional tools and records. No model call, provider call, or spending. This does not classify secrets or enforce the network. A production dispatcher has to send the checked projection to the verified recipient.

Building Roster keeps making the same point concrete: an available tool is not blanket permission to disclose.
